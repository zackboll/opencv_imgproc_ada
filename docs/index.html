OpenCV Imgproc Ada

A thick, idiomatic Ada 2022 binding for the OpenCV Imgproc module. It extends OpenCV Core Ada, which owns OpenCV.Core.Mat and the shared value types; the public operations are in the single package OpenCV.Image_Processing.

Explore the API reference →

The package specification is the authoritative API declaration. This reference is generated from the main branch and can describe operations newer than the latest Alire release. The repository README describes the OpenCV versions exercised by CI and the per-feature compatibility notes.

Build from source

The development manifest resolves opencv_core from a sibling checkout. Install the native OpenCV development library, pkg-config and a C++17 compiler, then:

git clone https://github.com/zackboll/opencv_core_ada.git core
git clone https://github.com/zackboll/opencv_imgproc_ada.git imgproc
cd imgproc
alr -n build

Basic usage

with OpenCV.Core;
with OpenCV.Core.UInt8_Access;
with OpenCV.Image_Processing;

procedure Example is
   use OpenCV.Core;
   use type OpenCV.UInt8_Value;
   Image   : Mat := Create (4, 6, (Depth => UInt8, Channels => 1));
   Blurred : Mat;
begin
   Image.Set_To (OpenCV.Make_Scalar (128.0));
   OpenCV.Image_Processing.Gaussian_Blur
     (Source      => Image,
      Destination => Blurred,
      Kernel_Size => (Width => 3, Height => 3),
      Sigma       => 1.0);
   pragma Assert (Blurred.Rows = 4 and then Blurred.Columns = 6);
   pragma Assert (UInt8_Access.Get (Blurred, 0, 0) = 128);
end Example;

Gaussian_Blur writes into Destination a Mat of the Source's geometry, depth and channel count; Source is not modified.
